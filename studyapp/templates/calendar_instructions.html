Calendar Integration Instructions

Learn how to export your study schedule to external calendar applications.

iCal Export

You can export your tasks and study plans as an iCal (.ics) file that can be imported into most calendar applications like Google Calendar, Apple Calendar, Outlook, etc.

  1. Navigate to the Calendar Export page
  2. Click the "Download iCal File" button
  3. Save the generated .ics file to your computer
  4. Import the file into your preferred calendar application:
    • Google Calendar: Settings → Import & export → Select file → Choose calendar → Import
    • Apple Calendar: File → Import → Select file → Choose calendar
    • Microsoft Outlook: File → Open & Export → Import/Export → Import iCalendar (.ics) → Select file

What Gets Exported

  • Tasks: All your non-completed tasks with due dates appear as calendar events
  • Study Plans: Your scheduled study sessions appear as calendar events
  • Event Details: Each event includes title, description, and time information
  • Reminders: Tasks due today or tomorrow get automatic reminders

Updating Your Calendar

Since this is a static export, you'll need to re-export and re-import whenever your schedule changes:

  1. Make changes to your tasks or study plans in the Smart Study System
  2. Repeat the export process above
  3. Re-import the updated .ics file into your calendar application (most apps will prevent duplicates)

Troubleshooting

Events not showing up?

Make sure you have tasks with due dates or study plans scheduled. Only items with dates are exported to the calendar.

Wrong time zone?

All events are exported in UTC time. Adjust your calendar application's time zone settings if needed.

Duplicate events?

Some calendar applications may create duplicates if you import the same file multiple times. Try deleting old imports before re-importing.
